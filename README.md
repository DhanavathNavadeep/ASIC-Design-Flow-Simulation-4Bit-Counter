# ASIC-Design-Flow-Simulation-4Bit-Counter
ASIC Design Flow Simulation Using Open-Source Tools. Designed and simulated a 4-bit synchronous counter using Verilog HDL, testbench verification, waveform analysis, and open-source EDA tools including Icarus Verilog and GTKWave. Developed as part of the Digital Electronics and VLSI Internship at Codec Technologies.
